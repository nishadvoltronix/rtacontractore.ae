2. Technical and content implementation

Canonicalization and delivery

  • SITE_URL defaults to the confirmed public apex and accepts only an HTTPS origin without credentials, paths, queries or fragments. This prevents malformed canonical and sitemap URLs. The old spelling rtacontractore.ae in launch instructions was corrected.
  • Canonical tags, Open Graph URLs, JSON-LD, sitemap and robots use one shared configuration. Sitemap contains only the nine canonical indexable routes; 404 is noindex and excluded. No misleading build-time lastmod is generated.
  • The local server redirects existing /index.html, service directory index aliases and missing trailing slashes directly to the clean route. It preserves queries, returns empty HEAD bodies with correct headers, rejects malformed paths, protects path containment, and retains genuine 404 responses and inline PDFs.
  • Static HTML exposes the primary heading, direct answer, qualification facts, FAQ answers and links without JavaScript. Current navigation, enquiry preparation, direct email/WhatsApp behavior, responsive imagery, lazy video and scroll effects are preserved.

Primary landing page and search intent

The existing street-lighting page is the primary commercial page; no competing keyword page or doorway route was created. For a styled preview use the local service page while the preview server is running.

  • Title/H1 target “Street Lighting Contractor in Dubai”; metadata describes cabling, coordination, certificate review and a project quotation.
  • The approval keyword appears naturally in a buyer question, answered immediately with the conditional status. Other terms describe road lighting, electrical cable works, NOC coordination and appointment requirements without keyword stuffing.
  • The certificate box is a text-readable evidence source with a direct PDF link, rather than an invented approval badge. The 40–70-word answer requirement is met with 56 words.
  • A documented substation/LV-room/warehouse project is labeled as related electrical experience, not rebranded as a street-lighting case study. Existing representative photographs retain their credits and context.
  • Scope and handover items are presented as matters to agree in a quotation. The page does not invent a standard street-lighting quality procedure, test results, project outcomes, guaranteed NOCs or response times.
  • Contextual links connect the primary page with cabling, electrical infrastructure, maintenance enquiry requirements, company credentials, the corporate project record and the preselected enquiry form.

Structured data and AI discovery

  • Each page connects its WebPage to the shared WebSite and GeneralContractor. GeneralContractor already is an Organization/LocalBusiness subtype, so no duplicate company entity was introduced.
  • Three evidence-backed categories—street lighting, underground cabling and electrical infrastructure—have Service entities linked both ways to their WebPage. Six service/enquiry pages have connected BreadcrumbList nodes matching the visible breadcrumb.
  • High-mast, LED/solar and street-lighting maintenance retain useful enquiry pages; Service markup is omitted pending company-specific capability evidence. This does not prevent ordinary page indexing.
  • NAP comes from shared configuration. The P.O. Box is correctly represented as postOfficeBoxNumber, not a postal code. Matching corporate Facebook, LinkedIn, Instagram and X links are included; the separate Switchgear Pinterest entity is not conflated with the contracting company.
  • No invented reviews, AggregateRating, certifications, named authors, reviewer identities or Article markup were added. Useful FAQ content remains visible without FAQPage rich-result claims; Google discontinued FAQ rich results in May 2026. See Google’s documentation updates.
  • The existing general robots allowance already permits search discovery. Search crawlers, training crawlers and user-triggered retrieval are distinguished in the crawler review. No security bypass, training-policy change or unnecessary bot group was added.
  • No llms.txt was added as a ranking tactic. Google’s generative AI guidance emphasizes useful, accessible content and states that this file does not improve Google visibility. No inclusion or citation guarantee is made.
